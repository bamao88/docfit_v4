# 模块 B：内容提取

> 状态：草案，待产品负责人确认
> 遵守 `00-product.md`：§2（B 不读模板、不决定目标位置和格式、不改写学生内容）、§3.3、§3.4、§4.4、§4.5、§4.6、§5。
> 角色边界见 `02-architecture.md`；产物格式见 `contracts/content-model.md`；代码位置见 `design/01-code-layout.md`。
> 本文**只回答**：流程、每步的输入输出与责任、已识别的风险。**不回答**：实现、产品决策。

## 1. 目标与边界

把一篇学生论文变成**内容模型**：忠实、有结构、有顺序、可溯源，不带格式。

- 不读学校模板，不知道最终会放在哪里。
- 不删字、不改字。识别不了的，标"待复核"或"暂不支持"，不丢。
- 学生的批注是内容的一部分，原样携带，不读作指令（`00-product.md` §4.6）。

## 2. 总流程

与模块 A 对称：

```
① 学生论文 Word
② 读取（代码）            对象清单 + source_id + 线索属性 + 自动编号显示文字
③ 区域判定（AI）          起点、终点、区域类型
④ 区域检查（代码）        完整、不重、连续；按类型查表决定是否进入⑤
⑤ 区域内判定（AI）        逐对象：属于哪个字段或哪个结构角色；编号前缀在哪
⑥ 判定检查（代码）        完整、唯一、词表内、前缀可定位
⑦ 组装（代码）            内容模型
⑧ 守恒校验（代码）        对照对象清单，文字一个不少、不多
```

## 3. 各步骤

### ② 读取
- 与 A 共用 `tool/read`，id 空间为 `S:`。
- 额外计算**自动编号显示出来的文字**（如"1.1"），因为它不在段落文字里（P13）。
- 生效格式只作为③⑤的线索，不进入内容模型。

### ③ 区域判定
- 区域类型取自封闭清单（`data/regions.yaml`）：封面、声明、目录、中文摘要、英文摘要、正文、参考文献、致谢、附录、其他。认不准选"其他"。
- 封面、声明、目录：按产品规则不迁移（D5、`00-product.md` §4.2），在内容模型里**明确记为"按规则不迁移"**，不是悄悄丢掉。

### ④ 区域检查
- 每个对象恰好属于一个区域，区域首尾相接。不通过只打回出问题的位置。
- 是否进入⑤，查 `data/regions.yaml`。S0 只有"正文"进入。

### ⑤ 区域内判定
- **字段类区域**（摘要等）：对象对应到字段（摘要正文、关键词）。
- **正文**：每个对象给一个结构角色（各级标题、段落、图、表、公式、题注、暂不支持）。角色只能取 `roles.yaml` 中已启用的；未启用的统一给"暂不支持"。
- **编号前缀**：标题、题注开头有没有手打编号（"第一章""1.1""图3-1"）、是哪几个字，是 AI 的判断。提示词是否专门说明，先不写，用黄金标注测准确度后再决定（不为假想的失误预先写提示词，P04）。代码只核对 AI 说的前缀确实是对象文字的开头，再拆分（P02）。

### ⑥ 判定检查
- 校验器：完整、唯一、词表内、前缀可定位（`design/03-harness-agent.md` §2）。

### ⑦ 组装
- 按阅读顺序和标题层级，把正文对象组成一棵树；单次字段直接成为字段值。
- 题注与图表的归属规则：待定（S1）。

### ⑧ 守恒校验
- 所有对象要么在内容模型里出现一次，要么出现在"按规则不迁移""暂不支持""待复核"清单中，三者之外不允许有遗漏。
- 内容模型里的文字（前缀 + 正文）拼起来，等于原对象的文字。
- 这是 V1（零丢失）在 B 这一层的机械检查。

## 4. 已识别风险

| # | 风险 | 对策 |
|---|---|---|
| B1 | 学生没用样式，标题只靠加粗、字号区分 | 视图给相对字号、加粗、居中等线索；层级跳跃只作为待复核提示 |
| B2 | 编号由 Word 自动生成，不在文字里 | ② 计算显示文字，作为线索和前缀来源 |
| B3 | 文本框、形状里的文字不在正文序列中 | ② 读取并标记位置；S0 归入"暂不支持" |
| B4 | 批注、修订痕迹 | 批注原样携带，锚定到所在文字（D16），不按批注改内容；修订痕迹的处理待 Q14 |
| B5 | 参考文献由文献管理软件的域生成 | 读域的显示结果；编号问题见 Q11，S2 处理 |
| B6 | 上下标（如 H₂O、m²）属于内容还是格式 | 待 Q3；S1 前决定 |

## 5. 本模块的验收

| 阶段 | 度量 | 标准来源 |
|---|---|---|
| ③④ 区域划分 | 与人工标注一致 | 学生论文的区域级黄金标注（待做） |
| ⑤⑥ 角色判定 | 与人工标注一致 | 正文角色的黄金标注（待做） |
| ⑧ 守恒 | 零遗漏、零改字 | 对象清单本身，无需标准 |
