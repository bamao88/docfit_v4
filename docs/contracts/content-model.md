# 内容模型（Content Model）

> 状态：草案 v0。遵守 `00-product.md` §3.3、§4.4、§4.5；D2（只保留内容，不保留格式）。
> 本文只回答：内容模型里有什么。**不回答**：B 怎么产出它（`modules/B-content-extraction.md`）。
> 生产者：B⑦。消费者：C。

## 1. 整体

| 项 | 含义 |
|---|---|
| 通用头 | 见 `design/04-data-and-runs.md` §2 |
| `source_sha256` | 学生论文哈希 |
| `regions` | 区域列表：类型、起止对象 id、处理（提取 / 按规则不迁移 / 其他） |
| `fields` | 单次字段 |
| `body` | 正文树 |
| `not_migrated` | 按产品规则不迁移的对象（封面、声明、目录） |
| `unsupported` | 当前阶段暂不支持的对象（S0 的图、表、公式） |
| `review` | 待复核的对象及原因 |

## 2. 单次字段

| 字段 | 含义 |
|---|---|
| `field` | 字段注册表中的字段名 |
| `value` | 内容（§4） |
| `sources` | 来源对象 id |

## 3. 正文树的节点

| 字段 | 含义 |
|---|---|
| `node_id` | 由来源 id 派生 |
| `role` | 结构角色（`data/registry/roles.yaml` 中已启用的） |
| `prefix` | 编号前缀，如"第一章""1.1""图3-1"；没有则为空 |
| `content` | 内容（§4），不含前缀 |
| `children` | 子节点（标题下的内容） |
| `sources` | 来源对象 id |

- 节点顺序 = 学生原始阅读顺序（V4）。
- 树里没有任何格式信息，也没有目录（`00-product.md` §4.2）。

## 4. 内容

S0：纯文字。

S1 起按角色扩展，结构不变，只增加内容形态：

| 角色 | 内容形态 |
|---|---|
| 图 | 图片二进制的引用 |
| 表 | 行、列、合并关系、单元格文字（范围待 Q3） |
| 公式 | 公式本身（OMML） |
| 行内语义 | 上下标等，是否算内容待 Q3 |
| 批注 | 锚定的文字范围 + 批注原文（作者、时间、回复），原样携带（D16） |
| 修订 | 待 Q14 |

## 5. 规则

1. 守恒：所有对象都出现在 `body`、`fields`、`not_migrated`、`unsupported`、`review` 之一，且只出现一次。
2. 不改字：每个节点的 `prefix + content` 等于来源对象的文字。
3. 新增角色和内容形态可以；已有字段不改名。
