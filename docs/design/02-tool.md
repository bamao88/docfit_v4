# Tool 设计

> 状态：草案。遵守 `02-architecture.md`（Tool 不知道流程、不做决定、不保存跨调用状态）、`00-product.md` §4.5。
> 本文回答：对象怎么切分、id 怎么生成、生效格式怎么算、编辑原语有哪些、执行后怎么校验。
> **不回答**：对象清单的字段（`contracts/object-list.md`）、何时调用哪个原语（`modules/`）。

## 1. 对象

- **对象 = 块级元素**：段落、表格、块级内容控件。表格整体是一个对象，内部单元格不单独作为对象（R8）。
- **按部件分开**：正文、各节页眉页脚、脚注、尾注各自成序列，对象带 `part` 属性（P07）。批注不读入。
- **段落内的特殊内容作为属性**：含图片、含公式、含域起止、带分页符、是否为分节结尾。
- **批注和修订**：作为段落内的锚点属性读入，不改动，供 B 携带、C 搬运（D16）。
- **复合关系作为"组"单独记录**：目录域跨多个段落、编号列表、内容控件、图片与题注。判定和编辑都以组为单位检查完整性（P13）。
- **空对象**：在对象清单里照常存在（Word 文件不变）；只在给 Agent 的视图里折叠成相邻对象的"前后留白"（R2）。

## 2. source_id

- 格式：`<文档>:<部件>:<序号>`，如 `T:body:0042`、`S:footer2:0001`。`T` 为模板，`S` 为学生论文，两个 id 空间互不引用。
- 文档本身的哈希写在对象清单的通用头里，不进 id，保证 id 短，便于 Agent 引用。
- **确定性**：同一个文件读两次，得到同样的 id。这是 Tool 的单元测试之一。
- **派生**：拆分产生 `T:body:0042.1`、`.2`；C 插入的对象用 `C:` 加内容节点 id。只由 `core/ids.py` 生成，Agent 不造 id（`00-product.md` §4.5）。

## 3. 生效格式

- 计算顺序：文档默认 → 段落样式链 → 编号定义 → 字符样式 → 直接格式。
- 输出规范化的属性集合：中西文字体、字号、粗斜体、对齐、缩进（含首行）、段前段后、行距、分页控制。"假居中"这类情况（P14）由缩进和对齐一起体现。
- **格式指纹** = 某类角色关心的那部分属性的哈希。用于：同一角色多个示例的冲突检测（R4）、执行后"保留的格式不变"比对。
- 学生文档同样计算，但只作为 Agent 判断标题层级的线索，不进入内容模型（D2）。

## 4. 编辑原语

所有原语都在一个**编辑会话**里执行：读取原件时建立 `id → XML 元素` 映射，之后一律按 id 定位，不按文字搜索（P06）；全部编辑完成后一次保存。

| 原语 | 作用 | 谁用 |
|---|---|---|
| `clear_text` | 删除段落内指定文字，段落本身保留 | A |
| `split` | 在指定句子之后把对象拆成两个，新 id 由代码派生 | A、B（拆编号前缀） |
| `slot` | 把示例内容换成带标签的内容控件（槽位） | A |
| `clone` | 复制原型对象（段落格式、字符格式、编号），换成新文字 | C |
| `remove` | 删除对象 | 只有 C 删除用完的原型 |
| `materialize` | 把预设角色的样式属性写到对象上 | C |
| `carry` | 跨文档搬运图片、批注等带关系的对象 | C（S1） |
| `toc` | 按参数生成目录域 | S4 预留 |

- A 不删除任何块级对象（D8）；"保留"不需要原语。
- 原语只接收"对象 id + 参数"，不知道这次编辑是为了什么。
- 新原语一个文件；原语之间不互相调用，组合由步骤脚本完成。

### 槽位为什么用内容控件

- Word 原生支持，不可见，不改变版式；
- 标签 `docfit:slot:<槽位实例>` 让 C 直接定位，不依赖示例文字；
- 最终 Word 保留这些控件，不做去除（D15）。用户在 Word 里点到时会看到控件边框，这是已接受的代价。
- **S0 需要实测**：Word 打开带块级内容控件的文档正常。

## 5. 执行后校验：预期 vs 实际

执行器不汇报自己做了什么（P12）。校验分三步：

1. **推导预期**：`pipelines/*/x_expect.py` 是纯函数，从"原件对象清单 + 判定"算出"执行后应有的对象清单"，不碰 Word。
2. **独立读取实际**：用 `tool/read` 重新读取产物，得到实际对象清单。
3. **比对**：`tool/diff/compare.py` 逐项比较文字、格式指纹、组的完整性，输出差异清单。

- A：因为不删块级对象，预期与实际按位置一一对应，比对最简单。
- C：预期 = 模板对象序列中，把每个槽位区域替换为内容节点序列；同样按位置对应。
- 差异清单就是回执；"零未授权改动"即差异清单为空（`modules/A-template-extraction.md` §6）。

## 6. 渲染

- `render/libreoffice.py` 输出 PDF 和页面图，只作辅助（P16）。
- 最终裁决用 Word 实机打开。是否接入 Word 自动化（更新域、导出 PDF），视 S0 的人工成本再定。
