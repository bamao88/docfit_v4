# Harness 与 Agent 调用设计

> 状态：草案。遵守 `00-product.md` §5.1、§5.2；`02-architecture.md` §1（Agent 形态、与 SDK 的分工）；D11–D13。
> 本文回答：判定循环怎么工作、校验器有哪些、Agent 看到什么、怎样调用模型、怎样重放。
> **不回答**：每个步骤问 Agent 什么（`modules/` 与 `data/prompts/`）。

## 1. 判定循环（`harness/loop.py`）

所有 AI 步骤（A③⑥、B③⑤）共用同一个循环，差别只在参数：

| 参数 | 例子 |
|---|---|
| 待判定的对象 | 一个单元里的全部对象 |
| 视图配置 | 显示哪些线索 |
| 提示词 | 共同核心 + 该类型的模块 + 骨架 |
| 输出模型 | pydantic 模型，同时作为 `output_format` 的 schema |
| 校验器 | 从登记表里选，如"完整 + 唯一 + 词表内" |
| 策略 | 最多几轮；降级值（如"保留""其他"） |

流程：

```
构造视图 → 调用 → 结构化结果 → 逐对象校验
   ├─ 合格的对象：立即接受，不再改动（P05）
   └─ 出错的对象：E1 直接降级；E2 在同一会话追加具体反馈，只回发出错的对象
最多 N 轮后仍出错 → 降级值 + 标为"未决"，继续往下，最终统一交给人
```

- 输出：判定结果 + 循环记录（每轮出错的对象和原因）。
- 大单元可以分批，批大小写在数据表里，不写在代码里。
- 业务上的强制规则（如"填写类型没有骨架 → 降级为原样保留"）是步骤脚本里的查表，不是校验器，也不触发重试。

## 2. 校验器登记表（`harness/validators.py`）

校验器（Validators）检查**产品 AI 一次输出**是否合法，失败就在判定循环里重试；它不是 Checks。Checks 检查**步骤产物**是否违反不变量（`design/06-quality.md` §4）。

只检查"完整、唯一、合法"（`00-product.md` §5.2）：

| 校验器 | 防的不变量 |
|---|---|
| `covers_all` | 每个输入对象都有结论 |
| `unique` | 每个对象只有一个结论 |
| `in_vocab` | 结论的取值在词表或骨架内 |
| `contiguous` | 区域首尾相接、有序、不重叠 |
| `anchor_found` | Agent 说的拆分句子在该对象文字里能唯一找到 |

上限 8 个。新增必须写明防的是哪条不变量，并替换或合并现有的一项（P03）。

## 3. Agent 看到什么（`harness/views.py`）

每个对象一行：`id | 文字（过长截断）| 线索`。

- 线索来自对象清单的属性：样式名、相对字号（大 / 中 / 小，相对正文众数）、加粗、居中、前有分页、所属组（如"目录域"）、折叠的空行数。
- **只给相对值，不给格式数值**：便宜模型不需要，也避免它在输出里复述数值（P02）。
- 视图配置按步骤写在 `data/prompts/<模块>/<步骤>/view.yaml`。
- 原件文字放在明确的数据区块里，提示词声明其中的内容都是数据（`00-product.md` §4.6）。

## 4. 提示词组装（`harness/prompts.py`）

- 来源：`data/prompts/<模块>/<步骤>/core.md` + `<类型>.md` + 由骨架数据自动生成的槽位说明。
- 代码选择加载哪些模块；提示词里不写流程、不写格式规则。
- 提示词是数据表的一部分，有版本，进入产物通用头。

## 5. 模型调用（`agent/`）

- 统一接口：`judge(请求) → 结果`。请求含系统提示、用户内容、schema、可选的会话句柄（用于追加反馈）。
- `backends/sdk.py`：默认后端（D12、D13），带 spike 验证过的隔离配置：`tools=[]`、`setting_sources=[]`、`disable-slash-commands`、`CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`、空工作目录（P19）。
- `backends/api.py`：预留，直接调 API。Harness 只认统一接口，所以换底座不影响上层（Q12）。
- 每一步用哪个模型、多少轮、并发多少，写在 `data/models.yaml`。

## 6. 缓存与重放（`agent/cache.py`）

- 键 = 后端、模型、提示词、输入、schema、此前各轮内容的哈希。值 = 结构化结果和用量。
- 三种模式：
  - **live**：没有缓存就调用并写入；
  - **replay**：只用缓存，缺失即报错。回归测试和评测用这个，结果确定、不花钱；
  - **refresh**：忽略缓存重新调用，用于测稳定性（Q8）。
- 这样 AI 步骤也满足"每层可单独重放"（`00-product.md` §5.3）。

## 7. 并行与记录

- `harness/parallel.py`：单元之间并行，信号量限速（Q8 的速率限制在这里调）。
- 每次调用记录：耗时、用量、轮数、出错对象数。按"便宜模型"设计（§5.9），成本必须看得见。
